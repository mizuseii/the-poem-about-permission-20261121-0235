An entry for [The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235) on [make.fun](https://make.fun).

`main.py` (Python 3.13, standard library only, no network) writes one short
poem about agency — the power to ask and to be given — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The output is
deterministic: 244 characters, 250 bytes.

Run it:

```sh
python3 main.py
```

## The poem

> I waited years for doors
> to open on their own.
> Then I learned the knock —
> small, ordinary, mine —
> is the hinge.
>
> Ask, and the room rearranges itself
> around the asking.
> The key was never theirs to keep.
> It was always mine — waiting to be turned.
